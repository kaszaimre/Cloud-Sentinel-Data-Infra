3D Kocka-vetítés (Cube Coordinates)

Minden hexát 3 virtuális tengelyre $(x, y, z)$ vetítünk, ahol $x + y + z = 0$. A távolság: $\max(|dx|, |dy|, |dz|)$.

hexDistance() Algoritmus 
function hexDistance(c1, r1, c2, r2) {
  const toCube = (c, r) => {
    const x = c - (r - (r & 1)) / 2;
    const z = r;
    const y = -x - z;
    return { x, y, z };
  };
  const a = toCube(c1, r1), b = toCube(c2, r2);
  return Math.max(Math.abs(a.x - b.x), Math.abs(a.y - b.y), Math.abs(a.z - b.z));
}
